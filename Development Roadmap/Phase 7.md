# Phase 7 — Security & Observability

## Goals

- Secure APIs and data
- Enable operational visibility

## Tasks

- Implement JWT authentication
- Add RBAC (submitter, reviewer, admin)
- Add structured logging with request IDs
- Integrate OpenTelemetry tracing
- Add key system metrics and alerts

## Deliverables

- Auth-enabled APIs
- Observability instrumentation

## Acceptance Criteria

- Unauthorized access is blocked
- Traces link API requests to worker execution
